# AirPulse business website

Upload the contents of this folder to a GitHub repository. `index.html` belongs at the repository root, not inside a second folder. In Settings → Pages, choose Deploy from a branch, then main and / (root). Enable HTTPS when available. No build command or dependencies are required. GitHub’s current guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

This is the customer-facing informational website. There are no prices, owner links, private catalog records, or passwords in this website. Publish the price book in an entirely separate repository if you want to host that too.

The form opens an email-options dialog with Open Gmail, Open email app, and Copy request buttons. The draft is addressed to service@airpulseaz.com. Gmail opens in a new tab; the email-app option needs a configured mail handler. The copy option works as a fallback, with manual text selection if clipboard access is unavailable. It does not send an email automatically or book an appointment. Instagram points to @AirPulseAz.

Before launch, verify service areas and contact details. The business phone is 623-203-2367, with tap-to-call links. The user-supplied license number is ROC #368147. No insurance claims, warranties, testimonials, emergency availability, or financing promises have been invented.

Edit copy in index.html, styling in style.css, and email form behavior in script.js. The supplied AirPulse logo is in assets/airpulse.png. All local links use relative paths, so both GitHub project URLs and custom domains work.

GitHub Pages is a static service. Check GitHub's current use limits for commercial sites: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits . This package does not implement checkout, payments, customer accounts, or commercial SaaS. The same folder can be deployed to another static host without conversion.
